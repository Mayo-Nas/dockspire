# Contributing to Dockspire

Dockspire is owner-maintained. Only `Mayo-Nas` currently has write and merge access; additional collaborators are invited explicitly. Public visibility, contributor attribution and pull requests do not grant write or merge access to the official repository.

Outside contributors work in forks and may propose focused pull requests to `main`, subject to the project's licensing terms. The owner decides whether to accept changes and does not promise a response, support or maintenance of forks and custom versions.

Before proposing changes, run the applicable [development checks](docs/DEVELOPMENT.md). Explain the problem, resulting behavior and validation in the pull request. Keep documentation and dependency notices current, and exclude credentials, private data and generated files. Changes are merged after maintainer review and successful CI.

`main` contains the complete source, tests, CI and release tooling. Runtime images remain minimal through packaging. See [repository and release policy](docs/GITHUB.md) for releases.

Dockspire is licensed under [Apache 2.0](LICENSE), with project attribution in [NOTICE](NOTICE). Retain third-party notices under `licenses/`.
